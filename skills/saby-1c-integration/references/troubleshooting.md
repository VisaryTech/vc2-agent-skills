# Диагностика интеграции

Маршрут проверки и критерии остановки ниже — рекомендации скилла. Исправление конкретной ошибки сверяй с официальной статьей; оглавление ошибок не заменяет инструкцию по устранению.

## Зафиксировать проблему

Собери доступные сведения: этап сбоя, точный текст ошибки, время, воспроизводимость, версии платформы и конфигурации, режим клиента, ОС/разрядность, способ подключения/обмена, версии обработки и настроек, последние изменения. Для документа нужны направление, тип и ID/номер, организация и результат в обеих системах. Запроси только недостающие сведения, влияющие на следующую проверку.

## Выбрать ветку

| Симптом | Следующая проверка |
| --- | --- |
| Не создается подключение | Адрес/путь базы, пользователь, права внешнего соединения, лицензия, совместимость |
| Ошибка OLE/COM/ActiveX | ОС, разрядность и версия компонентов; статья для точного сообщения |
| Нет ответа Plugin, ошибка SSL | Транспорт, компоненты, сетевой доступ; не отключать проверку TLS как обход |
| Нет документа в списке | Организация, период, фильтры, поддержка типа документа выбранным решением |
| Документ не загружен либо появились дубли | Существующий объект и сопоставление, протокол обмена, обязательные реквизиты; не повторять массовую загрузку |
| Неверные строки или реквизиты | Номенклатура, контрагент, организация, договор, единицы, НДС и настройки |
| Статус расходится | Идентификатор и состояние в обеих системах, результат последнего обновления |
| Сбой синхронизации | Поддержка режима, отдельный каталог, протокол/ответ сервера, направления и журнал |
| Нет сертификата | Среда подписания, доступ к сертификату, поддержка локальной ЭП, полномочия и МЧД при применимости |

Начни с [проблем браузерной интеграции](https://saby.ru/help/integration/1C_set/problems) или [ошибок внешней обработки](https://saby.ru/help/integration/1C_set/modul/typical_errors). Для синхронизации открой раздел «Типовые проблемы» на [ее странице](https://saby.ru/help/integration/1C_synchron). Перейди в статью с совпадающим сообщением и проверь применимость к среде.

Проверяй по одной гипотезе с наблюдаемым результатом. После исправления повтори минимальный сценарий и сверь обе стороны. Если применимое исправление не помогло, собери диагностику и обозначь оставшуюся гипотезу; не цикли обновления, очистку или отправку. Изменение прав, безопасного режима, регистрации компонентов и конфигурации должно соответствовать запросу и инструкции для среды пользователя.

## Информация для поддержки

[Официальная инструкция](https://saby.ru/help/integration/1C_set/modul/techinfovo): в главном окне обработки при проблеме запуска либо в документе при проблеме с ним выбери «Сохранить тех. информацию», укажи каталог архива. Имя содержит дату и время.

Подготовь описание воспроизведения, ожидаемого и фактического результата, время сбоя, версии и выполненные проверки. Архив может содержать настройки и данные документов: не выводи его целиком в чат. Передачу в поддержку выполняй по поручению пользователя.

## Форма результата

Сообщи причину либо проверяемую гипотезу, подтверждающие факты, следующий шаг и признак успеха. Если доступно только чтение справки, назови результат рекомендацией: не заявляй, что подключение настроено или документ передан.
