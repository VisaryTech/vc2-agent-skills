# Выбор и настройка решения

Проверено по официальной справке Saby 26.10.2026. Перед настройкой открой актуальную инструкцию выбранного решения. Указания о пилоте и проверках ниже — рекомендации скилла, а не дополнительные требования производителя.

## Совместимость

[Поддерживаемые конфигурации](https://saby.ru/help/integration/1C_set/config): проверяй конкретную редакцию, способ подключения и нужные документы. Наличие платформы в списке не подтверждает поддержку любой конфигурации. Поддержка указанной редакции распространяется на ее релизы, но не на следующую редакцию. Сторонние расширения могут влиять на стабильность.

Для браузера отраслевые и корпоративные доработанные релизы с буквенным кодом не поддерживаются. В веб-клиенте/Fresh нельзя дорабатывать порядок загрузки и выгрузки; открытие опубликованной базы тонким клиентом — отдельный случай. Отсутствующая или существенно измененная конфигурация требует оценки доработки.

## Работа из браузера

[Обзор](https://saby.ru/help/integration/1C_set/1C_sbis): работа из кабинета Saby, перенос документов, отчетов, справочников и начальных остатков. Направление называй явно: из 1С в Saby или из Saby в 1С.

[Технические требования](https://saby.ru/help/integration/1C_set/1C_sbis/tech): локальные OLE ComConnector/Application предусмотрены для Windows; для macOS/Linux указан Web-клиент (Fresh). Не переноси ограничения браузерной интеграции на внешнюю обработку. Для подписи отдельно проверяй десктопное приложение Saby и СКЗИ, для ExtSDK — требуемые компоненты.

[Настройка соединения](https://saby.ru/help/integration/1C_set/setting): в Saby Docs открой «Настройки», блок «Интеграции»; в online.saby.ru — «Настройки/Интеграции». Выбери 1С, подключение и версию платформы, заполни параметры, дождись успешного соединения.

- ComConnector: более быстрый локальный вариант, возможны особенности измененных платформ.
- Application: более медленный локальный вариант; это не гарантия поддержки любых документов измененной конфигурации.
- Web-клиент (Fresh): подключение к облачной базе.

Эти подключения занимают лицензию 1С. Для другой комбинации пользователей Saby/1С или конфигурации создается отдельное подключение.

Рекомендация для пилота: выбрать организацию, один вид документа и небольшой период; проверить реквизиты, суммы, номенклатуру и связь с существующим документом перед расширением объема.

## Внешняя обработка ЭДО

[Обзор](https://saby.ru/help/integration/1C_set/modul): документооборот непосредственно в 1С. Файл зависит от режима: управляемое приложение 8.3, обычное приложение 8.2/8.3 либо отдельная обработка 7.7 с каталогом настроек. Для других платформ сверяй текущие загрузки, не подбирай файл по догадке.

[Настройка обработки](https://saby.ru/help/integration/1C_set/modul/set_vo): открой подраздел о правах, подключении, файлах настроек, работе с документами или подписании. Версия обработки и версия файлов настроек — разные параметры диагностики.

[Выбор способа обмена](https://saby.ru/help/integration/1C_set/modul/exchange):

| Способ | Что определяет выбор |
| --- | --- |
| API | Проверить поддержку клиента, лимиты запроса и способ подписания |
| SabyHttpsClient | Windows/Linux/macOS; локальная ЭП не поддерживается |
| SabyPluginConnector | Через Saby Plugin; большие пакеты; Linux/macOS требуют компонента |
| ExtSDK2 | Windows, Saby Plugin; сверить разрядность и системные требования |
| ExtSDK2Crypto | Шифрование через Plugin, ЭП на носителе; получатель должен поддерживать шифрование |
| Каталог | Saby Connect на рабочем месте; без авторизации при запуске обработки, без предпросмотра и раздела «Отправленные» |

Выбор каталога не отменяет прав на отправку. Не используй утверждение этой страницы об увеличении Base64 на 25% для расчета размера: длина кодирования — `4 * ceil(n / 3)`, JSON добавляет накладные расходы. Актуальные лимиты проверь перед реализацией.

Рекомендация: проверить совместимость и транспорт, скачать официальный файл, настроить доступ и сопоставления, проверить один документ. Для доработки открой подраздел API на странице обработки: его интерфейс нельзя автоматически считать прямым API Saby.

## Синхронизация учета

[Официальный порядок](https://saby.ru/help/integration/1C_synchron): предназначена для локальной 1С; недоступна для 7.7, Fresh, веб-сервера и толстого клиента. Обмен использует механизмы распределенной базы и файловый сервер. Транспорт зависит от конфигурации: FTP, SFTP или явный FTPS; неявный FTPS не поддерживается. Для ЗУП 2.5 и БП 2.0 FTPS недоступен; страница также оговаривает ограничения типовых конфигураций для FTPS. Уточняй применимый вариант до выбора протокола.

До настройки нужны копия и тестирование базы; каждому подключению выделяется отдельная папка сервера. Последовательность: соединение через ComConnector/Application → предопределенные данные → сопоставление и загрузка недостающих объектов → FTP-подключение → настройка 1С → направления по объектам → автоматизация при необходимости → проверка результата.

Рекомендация скилла: для каждого типа объекта определить ведущую систему и правила изменения; сначала выполнить ограниченный ручной обмен. Расписание включать в рамках запроса после сверки результата. При неопределенном исходе проверить состояние объектов и обмена перед повтором записи.

## Специализированные сценарии

Это точки входа; изучай требования выбранной страницы до рекомендации установки.

- Кадровый документооборот: [расширение КЭДО](https://saby.ru/help/integration/1C_set/kedo), [внешняя обработка КЭДО](https://saby.ru/help/integration/externa_processing), [обработка КЭДО для Fresh](https://saby.ru/help/integration/1C_set/vo_fresh).
- Проактивные больничные и обмен с СФР: [расширение СЭДО](https://saby.ru/help/integration/1C_set/sedo).
- Бонусы при продажах: [система лояльности](https://saby.ru/help/integration/1C_set/lsand1c).
- Для ESD и ЭПД перейди к соответствующему подразделу [основной страницы](https://saby.ru/help/integration/1C_set). Не применяй к ним процедуру установки обычной обработки ЭДО.
