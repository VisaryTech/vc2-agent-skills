# Получение параметров PaddleOCR

1. Получи у администратора развёрнутого сервиса адрес API и ключ доступа.
2. Передай оба параметра в окружение процесса, запускающего клиент.

| Параметр | Где взять |
|---|---|
| `OCR_API_URL` | Корневой адрес сервиса PaddleOCR, без `/docs` и `/v1/ocr/jobs`. |
| `OCR_API_KEY` | Ключ доступа из печатных ASCII-символов без пробелов и управляющих символов, выданный администратором этого сервиса; клиент передаёт его в заголовке `X-API-Key`. |

Оба параметра обязательны и должны относиться к одному сервису. Адреса по умолчанию нет. Клиент не загружает `.env` автоматически.

После настройки выполни из каталога навыка:

```bash
python scripts/ocr.py check-env
python scripts/ocr.py check
```

`check-env` проверяет наличие и формат параметров без подключения к API и вывода их значений. Успех: `{"ok": true}`, код выхода 0. Ошибка: `{"ok": false, "error": "configuration_error", "message": "…"}`, код выхода 2.

После успешного `check-env` команда `check` проверяет состояние сервиса, готовность к распознаванию и принятие ключа. Она требуется перед новой отправкой; команды `status` и `result` можно выполнять без неё, даже если модели временно не готовы. Документация API доступна по пути `/docs` относительно `OCR_API_URL`.

Не передавай секреты в чат и не сохраняй их в репозитории.
