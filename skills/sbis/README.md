# СБИС ЭДО

Скилл позволяет находить и читать документы СБИС (Saby), проверять их состояние, скачивать вложения и подписи, создавать и обновлять исходящие черновики через запросы на естественном языке.

## Возможности и ограничения

Поиск поддерживает фильтры и обход страниц. Чтение возвращает состояние документа, редакции и вложения; выгрузка включает доступные подписи.

Обновление доступно только для редактируемых исходящих черновиков с явным разрешением изменений. Подписание, отправка, утверждение, отклонение, удаление и фоновая синхронизация не поддерживаются; подписать и отправить черновик можно в интерфейсе СБИС.

## Требования и настройка

Нужны Python 3.10+, подключение приложения с сервисным доступом к Saby и права на нужные организации. Сторонние библиотеки не требуются.

Параметры подключения задаются в окружении запускающего процесса:

| Переменная | Назначение |
| --- | --- |
| `SBIS_APP_CLIENT_ID` | ID приложения |
| `SBIS_APP_SECRET` | Защищённый ключ приложения |
| `SBIS_SECRET_KEY` | Сервисный ключ |

Токен доступа клиент получает самостоятельно. Подробные шаги настройки приложения, правила загрузки `.env`, использования `--env-file` и настройки кэша описаны в [справочнике авторизации](references/authentication.md).

## Проверка готовности

Из каталога скилла:

```bash
python3 scripts/sbis.py check-env
python3 scripts/sbis.py check
python3 scripts/sbis.py organizations
```

Первая команда проверяет настройки без подключения к API, вторая — доступ к списку организаций. Третья показывает доступные организации. Проверка списка организаций не подтверждает права на остальные операции. По умолчанию используется production; для тестовой площадки предусмотрен `--profile test` с отдельными параметрами доступа.

## Использование

Примеры запросов к агенту:

- «Найди исходящие документы нашей организации за октябрь».
- «Покажи состояние документа и скачай его вложения».
- «Скачай документ целиком ZIP-архивом с вложениями и подписями».
- «Подготовь изменение примечания в этом черновике, сохранив остальные вложения».

[Справочник команд](references/documents.md) содержит примеры CLI, форматы JSON, правила обновления и восстановления после ошибок записи.

Для выгрузки одним ZIP через `Документ.СсылкаНаАрхив`:

```bash
python3 scripts/sbis.py download DOCUMENT_ID --archive --output /tmp/sbis-export
```

ZIP сохраняется без распаковки; лимит клиента — 60 МиБ на архив. Если ссылки нет, возвращается `archive_unavailable`. При `archive_not_ready` повтори команду через 5–10 секунд: архив ещё готовится, автоматических повторов нет.

## Проверки разработки

```bash
python3 -m unittest discover -s tests -v
```

Тесты работают автономно с подменённым транспортом. Успех тестов не подтверждает права доступа или совместимость с конкретной площадкой.
