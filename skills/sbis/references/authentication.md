# Получение секретов СБИС/Saby

1. С правами управления подключениями открой «Настройки» → «Система» → «Безопасность» → «Подключения к Saby».
2. Добавь приложение или открой существующее. Включи сервисный доступ и настрой права на нужные организации и операции ЭДО.
3. Выбери авторизацию «по сервисному ключу» и сохрани приложение.
4. В карточке приложения получи три параметра:

| Параметр | Где взять |
|---|---|
| `SBIS_APP_CLIENT_ID` | «ID подключения» / ID приложения (`app_client_id`). |
| `SBIS_APP_SECRET` | Покажи и скопируй «Защищенный ключ» (`app_secret`). |
| `SBIS_SECRET_KEY` | Скачай файл в строке авторизации по сервисному ключу и возьми значение ключа (`secret_key`), а не имя файла. |

Все три параметра должны относиться к одному приложению и выбранной площадке. Одноразовый пароль не подходит. Токен CLI получает самостоятельно.

Не передавай секреты в чат и не сохраняй их в репозитории.

Справка Saby: [добавление приложения](https://saby.ru/help/integration/api/auth/add_app), [получение параметров](https://link.saby.ru/page/kbase_entity/3033991d-f3da-41b6-9b8b-4c719df25e5a?folderId=fe0094d9-c5d6-43f3-97d8-63eaaa4b4ab5).
