# Контроль сохраненных данных

После последней записи перечитай документ отдельным GET через `get` из `1c-odata` и сравни с ожидаемыми значениями:

- вид операции, организацию, поставщика и договор;
- количество строк, номенклатуру, количества и суммы;
- счета учета, счета НДС и способ учета НДС.

Для других документов учитывай соответствующие роли контрагентов и реквизиты операции. Неприменимость поля подтверждай правилами, а не его отсутствием в подготовленных данных.

Импорт завершен только после сверки. Если чтение недоступно, сообщи, что результат не проверен, и не объявляй импорт завершенным.

При расхождении остановись и сообщи ожидаемые и фактические значения. Не создавай документ повторно, не проводи его и не меняй права для обхода расхождения. При неизвестном результате записи следуй правилам восстановления `1c-odata`; не повторяй создание вслепую.
