# Проверка до записи

До записи проверь обязательность и согласованность данных: OData может не воспроизводить автоматическое заполнение формы, а успешный `--dry-run` из `1c-odata` не подтверждает хозяйственную корректность.

Зафиксируй ожидаемые значения для [контроля сохраненных данных](readback-verification.md).
