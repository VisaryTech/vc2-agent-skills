# Операция и сопоставление реквизитов

Для выбранной операции используй сопоставление реквизитов, подтвержденное для конкретной конфигурации.

Через `1c-odata` исследуй структуру документа, связанные справочники и настройки базы. Подтверждай назначение реквизитов настройками, документацией конфигурации или уточнением пользователя. Структура не доказывает бизнес-правило; существующие документы служат примерами, а не универсальным шаблоном.

Для существенных реквизитов шапки и строк зафиксируй источник значения, условие заполнения, обязательность, значения по умолчанию, зависимости и основание правила. Отделяй предположения от подтвержденных правил; недоступные через OData настройки отмечай как пробелы.
