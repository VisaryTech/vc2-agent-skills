# 1С через стандартный OData

Скилл позволяет работать с опубликованными данными 1С из запросов на естественном языке. Например: найти номенклатуру, показать заказы за период, получить остатки или подготовить изменение реквизитов.

## Возможности

- Поиск сущностей и изучение их структуры по метаданным публикации.
- Чтение, фильтрация и подсчёт записей, получение представлений ссылок и связанных объектов.
- Срезы, остатки и обороты регистров.
- Создание, изменение, пометка удаления и физическое удаление объектов с предварительным просмотром.

Проведение и отмена проведения, изменение и удаление проведённых документов не поддерживаются. Доступные операции зависят от публикации и прав учётной записи. Бизнес-реквизиты и бухгалтерскую корректность определяет пользователь; метаданные описывают структуру данных.

## Требования и настройка

Нужны Python 3.10+ и существующая стандартная OData 3.0 публикация 1С с JSON. Сторонние библиотеки не требуются. Поддержка отдельных запросов зависит от версии платформы и настроек публикации.

Параметры подключения задаются в окружении запускающего процесса:

| Переменная | Назначение |
| --- | --- |
| `ONEC_ODATA_URL` | Корневой URL публикации, например `https://host.example/base/odata/standard.odata/`, без query, fragment и встроенных credentials |
| `ONEC_ODATA_USERNAME` | Логин учётной записи публикации |
| `ONEC_ODATA_PASSWORD` | Пароль учётной записи |
| `ONEC_ODATA_ALLOW_HTTP` | Необязательный флаг: `1` разрешает HTTP для тестовой базы; по умолчанию требуется HTTPS |

Файл `.env` автоматически не загружается. Права на данные и операции настраиваются в 1С.

## Проверка готовности

Из каталога скилла:

```bash
python3 scripts/onec_odata.py check-env
python3 scripts/onec_odata.py check
```

Первая команда проверяет настройки без подключения к 1С; вторая — доступ к метаданным публикации. Проверка подключения не подтверждает права записи. При ошибке настройки диагностика указывает имена переменных без вывода их значений.

## Использование

Примеры запросов к агенту:

- «Найди номенклатуру, в названии которой есть “кабель”».
- «Покажи остатки товара на указанную дату».
- «Подготовь изменение наименования этого элемента и покажи предварительный результат».

[Справочник CLI](references/cli.md) содержит команды, форматы JSON, фильтры, правила записи и коды ошибок. Запросы регистров описаны в [отдельном справочнике](references/registers.md).

## Проверки разработки

```bash
python3 -m unittest discover -s tests -v
```

Автономные тесты не подключаются к 1С. Интеграционная проверка чтения включается переменной `ONEC_ODATA_LIVE_READ_TESTS=1` с настроенным подключением; сущность можно указать через `ONEC_ODATA_LIVE_ENTITY`. Она читает метаданные и до двух записей, без записи в базу.
