# Локальное извлечение PDF

## Окружение

Пути ниже отсчитываются от каталога скилла. Python 3.11; локальный CPU.

```bash
python3.11 -m venv /tmp/pdf-markdown-venv
/tmp/pdf-markdown-venv/bin/python -m pip install -r scripts/requirements.txt
```

Для извлечения готового текстового слоя (`--ocr never`), рендеринга и вырезок достаточно `PyMuPDF==1.26.6`. PaddleOCR импортируется только при необходимости OCR. Не меняй зависимости чужого проекта ради этого скилла.

По умолчанию для `--lang ru,en` используются `PP-OCRv5_mobile_det` и `cyrillic_PP-OCRv5_mobile_rec` с поддержкой кириллицы и латиницы. `ru` выбирает те же модели. Для другого языка передай один код PaddleOCR, например `--lang en` или `--lang fr`; произвольные списки языков не поддерживаются. Первое использование может скачать модели через PaddleOCR; для работы без сети заранее подготовь модели и передай оба каталога:

```bash
/tmp/pdf-markdown-venv/bin/python scripts/pdf_to_markdown.py extract document.pdf \
  --out /tmp/document-md \
  --det-model-dir /path/to/PP-OCRv5_mobile_det_infer \
  --rec-model-dir /path/to/cyrillic_PP-OCRv5_mobile_rec_infer
```

Эти каталоги задаются пользователем или обнаруживаются в доступном окружении; путь к прототипу не зашит. Модели должны быть совместимы с PaddleOCR 3.3.2 / PaddlePaddle 3.2.2. При передаче обоих каталогов скрипт отключает предварительную проверку доступности хостинга моделей через `PADDLE_PDX_DISABLE_MODEL_SOURCE_CHECK=True`, если переменная ещё не задана. Кэш загрузчика моделей принадлежит PaddleOCR; технический кэш результатов находится отдельно в выходном каталоге.

## Команды

```bash
python scripts/pdf_to_markdown.py extract document.pdf --out /tmp/document-md
python scripts/pdf_to_markdown.py extract document.pdf --out /tmp/document-md --pages 1-3,7
python scripts/pdf_to_markdown.py extract document.pdf --out /tmp/document-md --ocr never
python scripts/pdf_to_markdown.py render document.pdf --page 7 --out /tmp/page-7.png
python scripts/pdf_to_markdown.py crop document.pdf --page 7 --bbox 100,200,400,350 \
  --out /tmp/document-md/assets/page-0007-formula-01.png
```

- `--pages`: физические номера страниц с 1, диапазоны и списки; результат идёт в исходном порядке без дублей. По умолчанию все страницы. Некорректный диапазон отклоняется до обработки.
- `--ocr auto|always|never`: по умолчанию `auto`. OCR запускается для страницы с отсутствующим/повреждённым текстом или растровой областью площадью от 0,5% страницы. OCR всей страницы позволяет находить текст в изображениях смешанного PDF. Мелкие растровые и векторные надписи, качество скрытого OCR-слоя и порядок колонок автоматически не проверяются; `--ocr always` принудительно перечитывает страницу.
- В `auto` черновик содержит текстовый слой и OCR-дополнения. Удаляются только совпадающие тексты с перекрывающимися координатами. Другие повторы/разночтения намеренно остаются до сверки. В `always` черновик использует OCR, но текстовый слой остаётся в кэше.
- `--dpi 300`: разрешение рендеринга для извлечения и просмотра. `crop` по умолчанию использует 600 dpi. В PaddleOCR длинная сторона ограничена 4000 пикселями: при запрошенной сверке проверяй мелкий текст больших листов увеличенными вырезками.
- `--threads 8`: потоки CPU. `--refresh`: пересчитать выбранные страницы без чтения кэша.
- `render` сохраняет полную страницу; `crop` — прямоугольник. Выходной формат — PNG. `--bbox x0,y0,x1,y1` задаётся в **пунктах PDF (72 на дюйм), в неповёрнутом пространстве страницы с началом слева сверху**, как `bbox` из кэша PyMuPDF. Скрипт учитывает поворот страницы. Не передавай пиксели изображения без пересчёта; область вне страницы отклоняется.

## Выход и продолжение

```text
DIR/
  .work/
    draft.md              # сырой черновик, не финальный .md
    manifest.json         # текущий PDF, настройки, страницы, ошибки
    cache/<hash>.json     # результаты успешно извлечённых страниц
    pages/page-*.png      # изображения для сверки по отдельному запросу
  document.md             # копия draft.md; при запросе на сверку — исправленный результат
  assets/                 # вырезки при сверке по запросу
```

Скрипт не создаёт окончательный `document.md` и не меняет уже существующий итоговый файл. Для обычной конвертации скопируй `.work/draft.md` в итоговый `.md` без чтения содержимого. При повторном извлечении обнови эту копию. Визуальная сверка выполняется только по явному запросу пользователя. `.work/` можно хранить для продолжения, пользователю достаточно итогового `.md` и `assets/`, если вырезки создавались.

Ключ кэша включает SHA-256 PDF, номер страницы, режим OCR, язык, dpi, потоки, версии движков, пути и SHA-256 файлов явно заданных моделей. Успешные страницы переиспользуются, ошибки и частичные страницы повторяются. После ошибки OCR текстовый слой, кандидаты таблиц и изображение страницы сохраняются; запись получает статус `partial` и не считается успешно обработанной. В режиме `always` черновик такой страницы использует доступный текстовый слой. Запись JSON атомарная. Повреждённый JSON пересчитывается. Имена изображений включают ключ кэша, чтобы смена PDF или настроек не подставила старый растр. При обновлении автоматически загруженных весов по тому же имени используй `--refresh`: содержимое внутреннего хранилища PaddleOCR не хешируется. Не запускай несколько процессов с одним выходным каталогом одновременно.

В кэше страницы находятся `native_blocks` (строки, span-ы, шрифты, координаты), `image_regions`, `ocr_lines` (текст, координаты, confidence), `table_candidates` (ячейки, строки и геометрия) и `issues`. Нативный поиск таблиц — вспомогательный: на сканах таблица может отсутствовать или быть определена неверно. Все кандидаты имеют статус `unverified`. Сырой текст не нормализуется, число не преобразуется в float. При запросе на восстановление структуры таблиц сканов используй изображение, OCR и при необходимости вырезки; фиксированной сетки колонок нет.

Код `0` означает завершение технического извлечения выбранных страниц; `2` — ошибку аргументов, входного PDF или частичную обработку. OCR с пустым результатом отдельно отмечается в замечаниях; при обычной конвертации сохрани эту неопределённость без просмотра страницы. Ошибки отдельных страниц записываются в манифест; остальные страницы продолжают обрабатываться. PDF с паролем не поддерживается: нужен доступный разблокированный экземпляр. После прерывания повтори команду, проверь `processed_pages` (успешные страницы), `partial_pages` (страницы со сбоем OCR и сохранёнными данными), `complete`, ошибки и соответствие выбранному диапазону по манифесту. Поле `review_status: pending` означает отсутствие визуальной сверки и не обязывает её выполнять. При явном запросе на сверку агент фиксирует её прогресс отдельно в `.work/`.

## Проверки разработки

```bash
python -m unittest discover -s tests -v
```

Тесты требуют только PyMuPDF; OCR подменяется в тестах смешанного PDF и восстановления после ошибки. Реальный PaddleOCR проверяй отдельно на доступном скане с локальными моделями. Не добавляй PDF заказчика, модели, выходные файлы и журналы в репозиторий.

## Устройство кода

Точка входа — `scripts/pdf_to_markdown.py`. Она запускает CLI из соседнего пакета `scripts/pdf_markdown/`; при копировании скрипта переноси пакет вместе с ним.

- `cli.py` — аргументы команд и коды завершения.
- `extraction.py` — обработка одной страницы и координация извлечения документа.
- `document.py` — открытие PDF, текстовый слой, кандидаты таблиц, рендеринг и вырезки.
- `ocr.py` — конфигурация OCR и лениво загружаемый адаптер PaddleOCR.
- `cache.py` — отпечатки PDF и настроек, чтение кэша и атомарная запись файлов.
- `draft.py` — объединение текстового слоя с OCR и сборка технического Markdown-черновика.
