# Настройка подключения

Установи зависимости в используемое Python-окружение:

```bash
python -m pip install -r requirements.txt
```

Параметры передаются внешним окружением процесса. Клиент не читает `.env`, не сохраняет учётные данные и не имеет значений по умолчанию.

| Переменная | Значение |
| --- | --- |
| `NETWORK_FOLDER_PATH` | Полный UNC-путь к корню рабочей папки: сервер, ресурс и необязательные вложенные папки. |
| `NETWORK_FOLDER_USERNAME` | Учётная запись SMB, при необходимости с доменом через обратный слеш. |
| `NETWORK_FOLDER_PASSWORD` | Пароль этой учётной записи. |

Все три переменные обязательны. Не вставляй значения в чат, командную строку или репозиторий. Настраивай их через защищённое окружение запуска. Требуется сетевой доступ к SMB по TCP/445; поддерживаются SMB 2/3, авторизация NTLM. DFS и переходы по ссылкам не поддерживаются.

```bash
python scripts/network_folder.py check-env
python scripts/network_folder.py check
```

`check-env` проверяет конфигурацию локально, без импорта SMB-библиотеки и подключения. Успех: `{"ok": true}`. `check` подключается и перечисляет корневую папку, не возвращая её содержимое. Ошибки содержат только безопасную категорию и сообщение, без параметров подключения. Коды выхода: 0 — успех, 2 — ошибка, включая неверные аргументы CLI.

Нет автоматического повтора записей. При `operation_failed` или `timeout` проверяй состояние через `stat`/`list` перед повторением. Передача с `--overwrite` заменяет файл только после завершения копирования; незавершённый временный файл по возможности удаляется. При невозможности очистки возвращается относительный `temporary_path` для последующей проверки.
