# Диадок ЭДО

Скилл позволяет находить и читать документы Контур.Диадока, проверять их состояние, скачивать файлы и подписи, создавать исходящие черновики и их изменённые копии через запросы на естественном языке.

## Возможности и ограничения

Поиск поддерживает фильтры и обход страниц. Документы доступны по идентификаторам сообщения и вложенной сущности; выгрузка включает файлы и подписи.

Изменение черновика создаёт новую копию, исходный черновик сохраняется. Копирование ограничено поддерживаемыми вложениями и комментариями. Подписание, отправка, удаление, генерация УПД и фоновая синхронизация не поддерживаются; подписать и отправить черновик можно в интерфейсе Диадока.

## Требования и настройка

Нужны Python 3.10+, доступ к API Диадока и учётная запись с правами на нужные ящики. Сторонние библиотеки не требуются.

Параметры подключения задаются в окружении запускающего процесса:

| Переменная | Назначение |
| --- | --- |
| `DIADOC_CLIENT_ID` | ID приложения |
| `DIADOC_CLIENT_SECRET` | API-ключ приложения |
| `DIADOC_REFRESH_TOKEN` | Refresh token из Кабинета интегратора |

Access token клиент получает и обновляет самостоятельно. Подробные шаги получения параметров, правила загрузки `.env` и использования `--env-file` описаны в [справочнике авторизации](references/authentication.md).

## Проверка готовности

Из каталога скилла:

```bash
python3 scripts/diadoc.py check-env
python3 scripts/diadoc.py check
python3 scripts/diadoc.py organizations
```

Первая команда проверяет настройки без подключения к API, вторая — доступ к списку организаций. Третья показывает доступные организации и ящики. Для работы с документами нужен выбранный BoxId; проверка списка организаций не подтверждает права на все операции.

## Использование

Примеры запросов к агенту:

- «Найди входящие документы за октябрь в указанном ящике».
- «Покажи состояние документа и скачай его файлы с подписями».
- «Подготовь изменённую копию этого черновика и покажи предварительный результат».

[Справочник команд](references/documents.md) содержит примеры CLI, форматы JSON, ограничения копирования и правила восстановления после ошибок записи.

## Проверки разработки

```bash
python3 -m unittest discover -s tests -v
```

Тесты работают автономно с подменённым транспортом. Реальные чтения и записи через API ими не проверяются.
