# ЭДО и интеграция с 1С

Скиллы для работы с электронным документооборотом через API СБИС (Saby), Контур.Диадока и OData 1С:Бухгалтерии 3.0.

| Скилл | Возможности | Настройка доступа |
| --- | --- | --- |
| [СБИС](skills/sbis/SKILL.md) | Поиск и чтение документов, проверка статусов, скачивание вложений и подписей, создание и обновление исходящих черновиков | [Авторизация](skills/sbis/references/authentication.md) |
| [Диадок](skills/diadoc/SKILL.md) | Поиск и чтение документов, проверка статусов, скачивание файлов и подписей, создание исходящих черновиков и их изменённых копий | [Авторизация](skills/diadoc/references/authentication.md) |
| [1С OData](skills/1c-odata/SKILL.md) | Чтение справочников, создание контрагентов и импорт первички без проведения | [Настройка и сценарии](skills/1c-odata/README.md) |

Скриптам требуется Python 3.10 или новее; сторонние библиотеки не нужны. Порядок работы и сценарии CLI описаны в соответствующем скилле.

Подписание и отправка документов выполняются в интерфейсе оператора ЭДО. Секреты авторизации, входные JSON и выгруженные документы храните вне репозитория.
